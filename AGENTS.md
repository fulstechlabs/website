# Fulstech Website

This repository owns the public Fulstech corporate website.

- Keep the site static and compatible with GitHub Pages.
- Keep documentation content in `fulstechlabs/docs`.
- Keep canonical reusable identity assets in `fulstechlabs/brand`.
- Copy only approved, pinned brand exports into `public/brand`; do not load the
  private brand repository at runtime.
- Keep Marketplace, Docs, Support, and policy links explicit and verifiable.
- Deploy from `main` through the GitHub Pages workflow.
